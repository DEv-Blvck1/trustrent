# TrustRent 🏠

> Rental Agreement & Payment Manager for Nigerian tenants

In Nigeria, most rental agreements are verbal or on crumpled paper. Tenants lose caution fees, miss lease renewals, have no proof of payments, and can't track landlord promises. TrustRent fixes all of that.

## Real Problem Solved
- ₦150B+ in caution fees disputed or lost annually in Nigeria
- Most tenants have no receipt or proof of rent payments
- Lease expiry surprises leave people scrambling for housing
- No record of verbal agreements ("he said he'd fix the roof")

## Features
- 🏠 Add and manage multiple properties
- 📋 Track rent payments with receipt numbers + paid/pending/overdue status
- 📅 Lease timeline with days-remaining countdown + renewal alerts (60-day warning)
- 💰 Full financial summary: rent + caution fee + agent fee + total outlay
- 📞 One-tap call to landlord or agent
- 📝 Notes tab: document defects on arrival, verbal agreements, dispute records
- 💡 Move-in checklist tip: "document defects as evidence"

## Tech Stack
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React**
